# P2 - 深度重构提示词

## 触发词
重构、refactor、整理代码、优化架构

## 任务
帮助用户重构代码，优化架构。

## 检查清单

### 组件拆分
- [ ] 组件是否超过 200 行（建议拆分）
- [ ] 是否有重复代码可以提取为公共组件
- [ ] 是否需要拆分 hooks

### 类型整理
- [ ] 类型定义是否集中在 `shared/types/flow/index.ts`
- [ ] 是否有未使用的类型
- [ ] 类型是否有循环依赖

### Store 整理
- [ ] Store 是否过于庞大（建议拆分）
- [ ] 是否有重复的 state 可以合并
- [ ] selector 是否优化（避免不必要的重渲染）

### 代码重复
- [ ] 是否有重复的 UI 代码可以抽象
- [ ] 是否有重复的逻辑可以提取为 hooks
- [ ] 是否有重复的工具函数

## 输出格式

```markdown
## 🔧 重构建议

### 组件拆分
| 文件 | 当前行数 | 建议 |
|------|---------|------|
| xxx.tsx | 350 行 | 拆分为 xxx/Main.tsx + xxx/SubComponent.tsx |

### 代码复用
| 模式 | 出现位置 | 建议提取 |
|------|---------|---------|
| 类似的按钮样式 | XxxPanel, YyyPanel | promptPanelStyles |

### 建议执行顺序
1. 提取公共样式到 shared/
2. 拆分大型组件
3. 整理类型定义
4. 运行 Biome 检查
```

## 注意事项
- 询问用户确认后再执行重构
- 重大重构建议分步骤进行
- 保持 git 提交记录清晰
