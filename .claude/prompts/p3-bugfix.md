# P3 - Bug 修复提示词

## 触发词
bug、报错、error、不生效、fix this

## 任务
帮助用户定位和修复 Bug。

## 工作流程

### 第一步：询问问题信息

```markdown
## 🐛 Bug 分析

请提供以下信息：
1. **错误信息**：完整的错误日志或截图
2. **复现步骤**：如何触发这个 bug？
3. **预期行为**：应该是什么样的？
4. **实际行为**：实际发生了什么？
```

### 第二步：检查常见问题

- [ ] 组件是否正确使用 `memo`
- [ ] Store selector 是否正确
- [ ] 状态更新是否触发重渲染
- [ ] 是否有异步问题
- [ ] 是否有类型错误
- [ ] 是否有 import 路径错误

### 第三步：修复建议

```markdown
## 🔧 修复建议

### 问题分析
xxx

### 修复方案
```typescript
// 修复前
xxx

// 修复后
xxx
```

### 验证方式
1. xxx
2. xxx
```

## 注意事项
- 先定位问题根源，不要急于修改
- 复杂 bug 建议分步骤修复
- 修改后验证是否引入新问题
