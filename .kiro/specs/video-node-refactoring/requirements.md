# 视频节点重构 — 需求文档

## 用户故事

### US-1：新版视频节点创建

作为一个画布用户，我希望能够创建一个新版视频节点，以便预览重构后的视频生成 UI。

- **US-1.1**：右键菜单中提供"新建生成视频节点（新版）"入口，创建类型标识为 `newVideoNode` 的节点
- **US-1.2**：新节点在画布上正常渲染，包含输入/输出 Handle，可参与连线
- **US-1.3**：新节点的创建不影响已存在的旧版视频节点
- **US-1.4**：新节点初始展示占位内容区域，无真实视频数据

### US-2：新版视频节点基础外观

作为一个画布用户，我希望新版视频节点的视觉风格与旧版一致。

- **US-2.1**：节点尺寸根据 `aspect_ratio` 动态计算（默认 16:9）
- **US-2.2**：支持选中态高亮（紫色边框 + 四角装饰 + 发光效果）
- **US-2.3**：Handle 在选中/悬停时可见
- **US-2.4**：右键上下文菜单支持复制、删除

### US-3：底部面板布局（Mock 数据）

作为一个画布用户，我希望在新版视频节点底部看到一个完整的视频生成面板布局，所有数据和交互在初期均为 Mock 实现。

#### US-3.1：模式切换按钮行

- US-3.1.1：展示五个模式按钮：「文生视频」「全能参考」「图生视频」「首尾帧」「图片参考」
- US-3.1.2：当前选中「全能参考」，有视觉高亮
- US-3.1.3：点击切换模式时更新选中态（Mock，无实际行为）

#### US-3.2：参考图缩略图区域

- US-3.2.1：展示参考图缩略图区域，固定 3 张占位图，水平排列
- US-3.2.2：每张缩略图带数字标记（1、2、3）
- US-3.2.3：参考图支持可拖拽排序（用 @dnd-kit 实现），拖拽时其他卡片让位过渡
- US-3.2.4：拖拽排序仅改变 UI 顺序，不与任何后端或 Store 同步
- US-3.2.5：鼠标悬停在缩略图上时，在缩略图上方弹出一个大图预览浮窗
- US-3.2.6：预览浮窗带圆角，图片完整展示，浮窗尺寸约为缩略图的 3-4 倍
- US-3.2.7：移出缩略图区域或点击其他区域时预览浮窗关闭

#### US-3.3：提示词输入框

- US-3.3.1：多行文本输入框（textarea），展示占位文字"描述你想要生成的画面内容，@引用素材"
- US-3.3.2：支持 `@` 触发提及候选项列表（Mock 数据，如 "@素材1"、"@素材2"）
- US-3.3.3：输入内容仅作为展示，不发送任何 API 请求

#### US-3.4：底部参数栏

- US-3.4.1：模型下拉选择器，默认值为"Seedance 2.0 VIP"，可切换其他 Mock 模型选项
- US-3.4.2：参数下拉选择器，展示格式为"16:9 · 720P · 5s"，可切换预设组合
- US-3.4.3：「翻译」按钮（Mock，点击无实际行为）
- US-3.4.4：数量下拉（默认"1个"）
- US-3.4.5：积分余额显示 "108/135"（Mock 数据）
- US-3.4.6：生成按钮（右侧向上箭头图标，Mock，点击无实际行为）

## 非功能需求

### NFR-1：纯 Mock 实现

- NFR-1.1：第一期所有交互数据均为静态 Mock，不调用任何 Store API、OSS API 或 AI API
- NFR-1.2：所有 Mock 数据集中定义在 `constants/mockData.ts` 文件中，方便后续替换
- NFR-1.3：Mock 数据包括：模型列表、参数预设、参考图 URL、提及候选项、积分余额

### NFR-2：架构预留

- NFR-2.1：组件结构和数据流向应预留"将来接入真实数据"的扩展点
- NFR-2.2：Store 中的 `"videoNode"` 类型判断在 Mock 阶段不做任何修改
- NFR-2.3：组件不直接引用旧节点的任何 Store action 或类型

### NFR-3：代码可维护性

- NFR-3.1：新节点目录结构按功能模块组织（components/、constants/、hooks/）
- NFR-3.2：Mock 数据与 UI 组件分离，Mock 数据集中在 constants 目录
- NFR-3.3：每个组件职责单一

### NFR-4：兼容性

- NFR-4.1：旧版视频节点在整个 Mock 阶段保持完全可用
- NFR-4.2：新旧节点可以在同一画布中同时存在

## 边界情况

### EC-1：Mock 与真实数据的边界

- Mock 阶段不调用任何真实的 API 或 Store 写操作
- Mock 数据文件后期可直接替换为真实数据源（API/SWR/Store）
- 所有 Mock 常量的 export 类型与真实数据一致，保证替换时类型安全

### EC-2：拖拽排序边界

- 仅参考图缩略图之间可拖拽排序
- 拖拽不持久化（刷新后恢复初始顺序）
- 拖拽仅改变 UI 顺序，不改变数据结构中的索引

### EC-3：旧节点不受影响

- 所有新增代码只放在 `New-VideoNode/` 目录下
- 不修改 `VideoNode/` 目录中的任何文件
- 不修改 Store 中 `"videoNode"` 相关的逻辑
